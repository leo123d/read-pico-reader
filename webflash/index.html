通过 WebSerial 在浏览器里直接写入固件，无需安装工具链。

MindReset Read Pico
ESP32-S3 · 4.7" 墨水屏 684 × 1216
  • 请使用桌面版 Chrome 或 Edge（需要 WebSerial）。
  • 用 USB 数据线连接开发板，然后点击上面的按钮。
  • 烧录会擦除整片 flash（阅读进度、WiFi 凭据会清空；VCOM 存在 PMU，不受影响）。
  • 本板没有 BOOT / RESET 按键，烧录流程会自动进入下载模式。
  • 烧录完成后设备自动重启，直接进入书架。

手动烧录

不想用浏览器，或者需要批量烧写时，可以下载合并镜像用 esptool 写入。

合并镜像：Read_Pico-merged.bin —— 从 0x0 一次写入（含 bootloader、分区表、应用）。 
python -m esptool --chip esp32s3 -p COMx -b 460800 \
  --before default-reset --after hard-reset \
  write-flash 0x0 Read_Pico-merged.bin

也可以按下面的分区地址逐段烧写： bootloader 0x0 · 分区表 0x8000 · 应用 0x10000。

烧录前准备

这是纯阅读固件，阅读外部中文书需要一张 TF 卡。

  • 准备一张 FAT32 的 TF 卡，插入开发板。
  • 把 TXT / EPUB 放进去，或开机后用「传书」页通过 WiFi 上传。
  • 阅读中文书需要完整中文 TTF，放到卡上 fonts/ 目录后在「字体」页选用。
